DX12 Plane Game
================

概要
----
DirectX 12 を使用した、三人称視点のフライトゲームです。
球体の惑星を飛行し、指定された空港への着陸と駐機を繰り返します。
地形、海、空港の配置はワールドのシード値に基づいて生成されます。
飛行モデルはゲーム向けの簡易モデルであり、実機の完全な再現ではありません。

主な機能
--------
・球体の惑星と、飛行方向を優先して生成する地形チャンク
・山岳地形、海面の波、霧
・ランダムな位置と滑走路の向きを持つ ALPHA / BRAVO 空港
・空港間の飛行ミッションと給油エリア
・速度、高度、時刻、日付、スロットル、燃料、目的地を表示する HUD
・ゲーム内時刻に連動する昼夜サイクル
・エンジン音、および任意の風音と BGM

プレイに必要な環境
------------------
・64 ビット版 Windows 10 / 11
・快適な動作には DirectX 12 対応 GPU と適切なグラフィックスドライバー
・現在の Release ビルドに対応する Microsoft Visual C++ v14 再頒布可能パッケージ（x64）

プレイするだけであれば、Visual Studio、CMake、Windows SDK は不要です。
別の PC での動作は環境によって異なります。

起動方法
--------
DX12PlaneGame.exe をダブルクリックしてください。
コンソール画面を表示せず、ゲームウィンドウが直接開きます。

実行ファイルと data フォルダーは、次のように同じ場所に置いてください。

  ゲームフォルダー/
    DX12PlaneGame.exe
    data/

別の PC に渡す際は、Release フォルダーの中身をまとめてコピーしてください。
EXE ファイルだけでは、モデルやテクスチャが読み込まれません。

操作方法
--------
W / ↑       : 機首を下げる
S / ↓       : 機首を上げる
A / ←       : 左にバンク・旋回
D / →       : 右にバンク・旋回
Shift        : スロットルを上げる
Ctrl（地上） : エンジン出力を落とし、車輪ブレーキをかける
Ctrl（飛行中）: スロットルを下げる
Space        : 地上ブレーキ
E 長押し     : 給油条件を満たしている場合に給油
R            : ミッション進行と燃料をリセットし、出発空港から再開
F            : 霧の有効・無効を切り替える
M            : 音声のミュートを切り替える
T            : ゲーム内時刻を 3 時間進める
Esc          : ゲームを終了する

ゲームウィンドウが選択されている場合にのみ操作できます。
N による目的地の自由選択と、H による瞬間移動は無効です。

ミッションの進め方
------------------
1. ALPHA 空港の滑走路からスタートします。
2. Shift で出力を上げ、速度が十分に上がったら S で機首を上げて離陸します。
3. HUD の指定空港、距離、旋回方向を確認し、目的地へ向かいます。
4. 指定空港に着陸し、エプロンにある黄色い F マークの駐機区画へ移動します。
5. 区画内で停止し、スロットルをアイドルまで下げると飛行が完了します。
6. 次の目的地が自動的に割り当てられます。必要に応じて給油してください。

空港の上空を通過しただけでは完了しません。
違う空港への着陸や、同じ区画での連続した駐機でも次の飛行は完了しません。
空港間の距離は約 3.5～5.5 km です。同じシードでは同じ配置になります。

給油方法
--------
両空港のエプロンに、黄色い枠と F マークの給油区画があります。
区画内で以下の条件を満たし、E を長押ししてください。

・地上にいること
・速度が 1 m/s 以下であること
・スロットルがほぼゼロであること

Ctrl で出力を落として停止できます。
空のタンクを満タンにするには約 8.3 秒かかります。
燃料消費量はスロットルと飛行時間に応じて変化します。
HUD の航続距離は目安であり、上昇や旋回、低速飛行などで実際の消費量は変わります。

昼夜サイクル
------------
日の出 : 06:00
正午   : 12:00
日没   : 18:00
夜間   : 18:00～翌日 06:00

1 日は実時間で約 10 分です。初期時刻は 06:30 です。
空港やプレイヤーの位置に関係なく、HUD の時刻に合わせて明るさが変化します。
日の出と日没には空と霧が暖色になり、夜には night.jpg の星空を表示します。
HUD の日付はゲーム内カレンダーであり、PC の現在時刻とは別です。

主なアセット
------------
data/model/Airplane/airplane.obj : 飛行機モデル
data/texture/plane_diffuse.png  : 機体のカラーテクスチャ
data/texture/plane_normal.png   : 機体の法線マップ
data/texture/field005.jpg       : 地形の基本テクスチャ
data/texture/field004.jpg       : 斜面の詳細テクスチャ
data/texture/sea.jpg            : 海面テクスチャ
data/texture/night.jpg          : 夜の星空テクスチャ

任意の音声ファイル（16 ビット PCM WAV、モノラルまたはステレオ）:
  data/SE/engine.wav
  data/SE/wind.wav
  data/BGM/flight.wav

engine.wav がない場合は、簡易的なエンジン音を生成します。
アセットを変更した後は、再ビルドしてゲームを再起動してください。

開発・ビルド
------------
必要なもの:
・Visual Studio の C++ 開発ツール
・Windows SDK（CMake の既定設定: 10.0.26100.0）
・CMake 3.20 以上
・C++20 対応コンパイラー

プロジェクトのルートフォルダーで次を実行します。

  cmake -S . -B build
  cmake --build build --config Release

生成された実行ファイル:
  build/Release/DX12PlaneGame.exe

data フォルダーはビルド時に実行ファイルの隣へコピーされます。
ビルド先のゲームが起動中だと EXE を更新できないため、先に終了してください。
OBJ の読み込みに外部ライブラリーは不要です。FBX の読み込みには任意の Assimp が必要です。

主なソース構成
--------------
src/main.cpp              : Windows アプリケーションの入口
src/engine/Engine.*       : 初期化とゲームループ
src/window/window.*       : ウィンドウとイベント処理
src/game/game.*           : ワールド、プレイヤー、時刻、ミッションの管理
src/game/FlightRoute.h    : 飛行ミッションの進行
src/player/player.*      : 飛行操作、移動、カメラ、地上ブレーキ
src/player/fuel.*        : 燃料の消費と補給
src/world/WorldGenerator.* : 地形チャンクの生成
src/world/Airport.*      : 空港配置、建物、滑走路、給油区画
src/world/DayNightCycle.* : 昼夜サイクルと照明
src/world/sea.*          : 波の設定
src/hud/hud.*            : HUD のレイアウトと文字アトラス
src/hud/hudshader.h      : HUD 用シェーダー
src/sound/sound.*        : XAudio2 による音声処理
src/DX12/dx12renderer.*  : DirectX 12 描画
src/shadersource.h      : 地形、海、空のシェーダー

現在の制限
----------
・飛行物理と着陸処理は簡易的な実装です。
・建物との衝突判定は未実装です。
・地形の描画除外、LOD、GPU 同期などには最適化の余地があります。
・必要な性能は解像度、GPU、ドライバーなどによって変わります。
